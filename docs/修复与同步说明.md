## 在 Ubuntu 使用

先把本次更新同步到虚拟机实际运行的项目目录。若 `~/Apollo/robocup_UESTC_log` 是以前从共享目录复制出来的副本，它与共享目录不会自动同步，需要更新这份副本。

在更新后的项目根目录执行：

```bash
chmod +x gradlew launch.sh start.sh
./gradlew clean build --warning-mode=fail
bash launch.sh --map-name kobe1 -all
```

`--map-name` 仅标记日志；服务器须另外选相同地图。等待队伍全部连接成功后，再在服务器界面开始仿真。日志运行时在 `logs/`，结束后在 `log-archive/kobe1/<时间编号>/`。
