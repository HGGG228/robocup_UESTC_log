三条最容易踩的坑

1. 为什么每个方法都 return this？

这是链式调用协议，框架要求返回值就是模块自己。如果随手改成 return null，框架下一步就崩。

this.navigationModule.calc().getResult()

2. if (getCountUpdateInfo() > 1) return this;

本回合的“已经做过了”开关，防止同一回合被重复调用时重复干重活。写法不统一（>1、>=2、<2、<=1 混用），语义要逐个人工核对。

3. 只写 calc() 是新手最常见的错

把“收消息 / 判变化 / 预处理”全塞进 calc()，会变成每回合重算全图，直接拖慢甚至超时。
